# pdf2md - PDF → Markdown

Команда для перетворення «цифрових» PDF (з текстовим шаром: LaTeX, ONLYOFFICE, Word) на Markdown, придатний для читання й для LLM.

Модуль: [`home/pdf2md.nix`](../home/pdf2md.nix), код: [`home/pdf2md/pdf2md.py`](../home/pdf2md/pdf2md.py).

## Використання

```sh
pdf2md book.pdf            # -> book.md поруч
pdf2md book.pdf out/book.md
```

Рисунки зберігаються в `images/` поруч із `.md` (лише якщо вони є). Книжка на 274 сторінки конвертується приблизно за 35 с на CPU.

## Що обрано і чому (жовтень 2026)

| Інструмент | Результат на CPU (без GPU) |
|---|---|
| **Marker 2** (datalab), режим `balanced` | Найкращий на olmOCR-bench (76 %), але потрібен VLM через llama.cpp: понад 20 хв на 5 сторінок, тобто ~18 год на книжку. Непридатний. |
| Marker 2, `--disable_ocr` | Швидкий (~1 хв), але зливає кожен лістинг коду в один рядок. |
| pymupdf4llm 0.3.4 (nixpkgs) | Без `pymupdf-layout`: 117 блоків коду замість 320, 103 заголовки замість 785, таблиці губляться. |
| **pymupdf4llm 1.28.2 + pymupdf-layout** | Обрано: правильні заголовки, таблиці та блоки коду. |

Для PDF із текстовим шаром OCR не потрібне: текст береться напряму, а моделі потрібні лише для розмітки.

Новіші пакети беруться з `uv.lock` через uv2nix (як graphify). Окремий overlay додає шлях до `libmupdf` для autoPatchelf у `pymupdf-layout`. У `PATH` виставляється лише `bin/pdf2md`, щоб python3 з цього середовища не конфліктував із python3 graphify.

## Що виправляє поверх pymupdf4llm

- **Пробіли в коді.** У pdfTeX-лістингах немає гліфів пробілу (`publicclassFoo{`). Тому пробіли й відступи відновлюються за координатами символів моноширинного шрифту.
- **Латинська `i` в українських словах.** pdfTeX часто дає `Нацiональний`. Усередині кириличних слів вона замінюється на `і`, а код не зачіпається.
- **Повністю моноширинні документи.** Якщо понад 90 % тексту набрано моноширинним шрифтом (типово для ONLYOFFICE-документів у Liberation Mono), документ виводиться як звичайний текст, а не як суцільний блок коду. Короткі рядки великими літерами (`ЛАБ 2`) стають заголовками `##`.

## Обмеження

- Скани без текстового шару не розпізнаються. Для них потрібне справжнє OCR, наприклад Marker `balanced`, але воно реалістичне лише з GPU.
- Формули LaTeX виходять як текст, а не як `$...$`.
- Поодинокі рядки коду можуть лишитися злиплими, якщо pymupdf4llm розбив рядок інакше, ніж він стоїть у PDF. Таке трапляється рідко: у книжці був 1 такий рядок на 320 блоків.

## Оновлення залежностей

```sh
cd home/pdf2md && uv lock --upgrade && cd ../.. && just home-switch
```
